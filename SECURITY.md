# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for a security problem.
Public reports tell attackers about the problem before it can be fixed.

Report it privately instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

This uses GitHub's private vulnerability reporting, so only the maintainers can see your report.

If that button is not available, contact the maintainer, @keerthanarameshdasari-hub,
through GitHub and ask for a private channel. Do not include vulnerability details in
the first message.

## What to expect

- We aim to acknowledge your report within **3 working days**.
- We will keep you updated while we investigate and fix it.
- Once a fix is released, we are happy to credit you in the advisory unless you prefer
  to stay anonymous.

## Scope

This is a demo repository used for learning CI/CD. It is not deployed to production, but
reports are still welcome, especially anything affecting the CI workflows in `.github/`.
